02Google Flow 실습

📌 Flow(플로우)란 무엇인가 글, 이미지, 영상 제작 과정을 '흐름(Flow)'으로 자동 연결해 주는 AI 도구입니다. 글(Text) → 이미지(Image) → 영상(Video), 한 화면에서 글을 쓰고, 이미지를 만들고, 영상으로 이어 붙이는 과정을 한 번에 처리합니다.

Flow 시작하기 — 로그인

  1. 구글 검색구글에 'Flow'를 검색해 공식 사이트로 접속합니다
  2. 로그인구글(Gmail) 계정으로 로그인합니다
  3. 계정 선택여러 계정이 있다면 사용할 계정을 선택합니다
  4. 크레딧 지급첫 가입 시 150 크레딧이 자동으로 지급됩니다

Flow 홈 화면 살펴보기

  1. 메인 홈 화면로그인하면 Flow의 메인 홈 화면이 나타납니다
  2. 새 프로젝트'+ 새 프로젝트' 버튼으로 새 작업을 시작합니다
  3. 크레딧 확인우측 상단 프로필 메뉴에서 보유 크레딧을 확인할 수 있습니다

Flow 기능

이미지 추가 — 이미지를 드래그하여 등록 가능(동영상·오디오 파일 등록 불가) · 프롬프트 입력창 · 필터와 검색을 통해 생성한 이미지·동영상 찾기

Flow 이미지 생성하기 — 프롬프트 입력

  1. 이미지 설명화면 하단 입력창에 원하는 이미지를 문장으로 설명합니다
  2. 비율 선택이미지 비율(16:9, 1:1, 9:16 등)을 먼저 선택합니다
  3. 모델 선택생성 모델(Nano Banana Pro 등)을 선택합니다
  4. 크레딧 소모생성 1회당 정해진 크레딧이 소모됩니다

Flow 이미지 생성 결과 확인하기 — 프롬프트 예시

예시 · Flow 이미지 생성 프롬프트
개발도상국 농촌 마을에서 한국인 봉사단원과 현지 주민이 서로 웃으며 대화하는 장면, 진정성 있는 교감, 따뜻한 분위기, 흙길과 전통 가옥, 자연스러운 생활 환경 디테일, 부드러운 자연광(golden hour lighting), 다큐멘터리 사진 스타일, ultra realistic, 4k, high detail

참조 이미지 + 프롬프트로 생성하기

동일한 캐릭터를 유지한 채, 프롬프트만 바꿔 새로운 장면을 만들 수 있습니다. 참조 이미지(기존에 만든 캐릭터 이미지) + 프롬프트(바꾸고 싶은 모습을 문장으로 입력) → 새로운 이미지, 같은 캐릭터 새로운 장면 완성. 참조 이미지의 인물·캐릭터·분위기를 그대로 유지하므로 동일 캐릭터로 여러 장면을 일관되게 제작할 때 유용합니다.

Flow 이미지 생성하기(참조 이미지+프롬프트) — 프롬프트 예시

예시 · 참조 이미지 활용 프롬프트

Flow 영상 생성 — 프롬프트 설계하기

ChatGPT 등 텍스트 AI로 장면별 영상 프롬프트를 미리 구성하면 더 정교한 결과를 얻을 수 있습니다.

ChatGPT에 입력 · 장면별 Flow 프롬프트 구성 요청
좋아! 이 5개의 각 장면을 'Flow'에서 영상으로 생성할 거야. 장면에 어울리는 프롬프트를 구성해 줘. 각 장면당 코드 블록으로 생성해 줘. 구글 정책에 위반되지 않는 단어와 내용으로 작성해 줘.

이렇게 만든 영어 프롬프트를 Flow의 입력창에 그대로 붙여 넣어 사용합니다.

Flow 영상 생성하기 — 실행 단계

  1. ① 참조 이미지 추가
  2. ② 프롬프트 입력
  3. ③ 생성 옵션 설정9:16, Veo 3.1
  4. ④ 다운로드설정 후 다운로드
⚠ 주의 업스케일 선택 시 추가 크레딧 소진과 시간이 더 소요됩니다.

Flow로 완성한 영상

참조 이미지를 바탕으로 프롬프트만 바꿔가며 같은 캐릭터의 새로운 장면을 이어갑니다. 장면 1 → 장면 2 → 장면 3 → 장면 4 → 장면 5. 5개의 장면을 모두 생성한 뒤 순서대로 이어 붙이면 짧은 영상이 완성됩니다.

★ 참고 · Google Flow Agent용 통합 프롬프트 (패들렛 자료)

대학생의 1분~1분 30초 자기 PR 영상 전체를 한 번에 설계하는 통합 프롬프트 예시입니다. 실제 수업에서는 강의 패들렛에서 전체 원문을 복사해 사용합니다 — 아래는 원문 앞부분(SCENE 1~2 시작) 예시입니다.

예시 · Google Flow Agent 통합 프롬프트(패들렛 복사용, 앞부분 발췌)
대학생의 1분~1분 30초 자기 PR 영상을 제작해줘. 영상의 목적은 단순한 자기소개가 아니라, '나는 어떤 강점을 가진 사람이며, 그 강점을 앞으로 어떻게 발전시킬 것인가'를 하나의 스토리로 보여주는 것이다.

[영상 기본 정보]
- 전체 영상 길이: 약 85~90초
- 화면 비율: 16:9
- 대상: 대학생 자기 PR/포트폴리오/취업용 영상
- 분위기: 자연스럽고 세련된 대학생 포트폴리오 영상
- 스타일: 현실적이고 감각적인 다큐멘터리 + 포트폴리오 영상
- 과장된 광고 영상처럼 보이지 않도록 할 것
- 밝고 깔끔한 분위기
- 자연스러운 카메라 움직임
- 장면 간 전환은 부드럽게
- 전체 영상에서 동일한 인물과 동일한 외모를 유지할 것
- 인물의 얼굴, 헤어스타일, 의상, 체형이 장면마다 바뀌지 않도록 할 것
- 실제 대학생이 자신의 프로젝트를 소개하는 듯한 자연스러운 연출
자막은 화면의 핵심 메시지만 간결하게 표시

[핵심 자기 PR 문장]
"저는 사람들의 취향과 반응을 세심하게 관찰하고, 사람들과 소통하며 얻은 다양한 생각을 아이디어로 발전시켜 나만의 결과물로 만들어가는 사람입니다."
이 문장을 영상 전체의 핵심 메시지로 활용해줘.

[핵심 강점]
1. 창의성, 2. 아이디어 구체화, 3. 완성도 추구, 4. 자기주도적 실행, 5. 협업과 소통
영상의 스토리는 반드시 다음 순서로 진행한다. 경험 → 행동 → 결과 → 강점 → 미래

======================== SCENE 1. 나를 한 문장으로 ========================
시간: 0~12초
화면: 대학생이 카메라를 정면으로 바라보며 자연스럽게 자기소개한다. 처음에는 인물 중심의 미디엄 샷으로 시작한다. 이후 본인이 작업한 디자인 프로젝트의 결과물이 짧게 오버랩된다.
대사: "저는 사람들의 취향과 반응을 세심하게 관찰하고, 사람들과 소통하며 얻은 다양한 생각을 아이디어로 발전시켜 나만의 결과물로 만들어가는 사람입니다."
자막: "관찰하고, 소통하고, 아이디어를 완성하는 사람"
연출: 첫 장면은 영상의 핵심 정체성을 명확하게 전달한다. 자연스럽고 자신감 있는 표정과 말투를 사용한다.

======================== SCENE 2. 경험 – 아이디어를 만나다 ========================
시간: 12~27초
화면: 프로젝트 초기의 모습을 보여준다. 스케치, 자료 조사, 메모, 디자인 레퍼런스를 살펴보는 모습. 아이디어를 고민하는 대학생의 모습을 자연스럽게 촬영한다.
대사: (이하 전체 SCENE 3~6 대사와 자막은 강의 패들렛의 원본 프롬프트 자료를 참고하세요)
📌 참고 위 프롬프트는 SCENE 1~2 도입부까지의 예시이며, 전체 SCENE 구성(경험→행동→결과→강점→미래)의 나머지 대사·자막은 강의 패들렛에 공유된 원본 자료에서 그대로 복사해 사용합니다.

보강 · CapCut 실습 시작 전 촬영 전에 알아야 할 연출 기법

구분내용
1. 카메라 앵글·움직임정면 앵글을 기본으로, 클로즈업·와이드 샷과 부드러운 패닝·틸팅으로 변화감 연출
2. 조명밝고 균일한 조명으로 얼굴이 잘 드러나게, 그림자·눈부심 없는 각도와 위치 확보
3. 배경단색 배경이나 소품으로 주인공에 초점을 맞추거나, 편안한 실내·야외 배경 활용
4. 편집 리듬감자막·BGM·트랜지션을 적절히 활용해 몰입도와 완성도를 높이는 편집

CapCut 설치 · 로그인 · 프로젝트 시작

  1. 캡컷 설치필수항목만 체크
  2. 로그인로그인 완료까지 진행
  3. 엔딩 설정 및 편집 시작
  4. 편집할 자료 불러오기편집할 사진 추가, 미리보기 창 확인

전환효과·편집효과

  1. 전환효과 추가영상과 영상 사이에 추가, 지속시간 결정, 효과 선택
  2. 편집효과 적용(조정)효과의 속도·분위기 설정, 뒤쪽 영상도 같은 방법으로 효과 적용
⚠ 주의 다이아몬드 표시는 유료 효과입니다!

템플릿 — 인트로 / 텍스트 편집 / 엔딩

  1. 인트로검색어로 '검은배경' 인트로 생성 → 바를 터치한 상태서 드래그로 길이 줄이기(10초→4초)
  2. 텍스트 작업 시작추가하면 플레이 헤드 뒤쪽에 바로 생성, 원하는 텍스트 입력
  3. 글씨 스타일 변경줄 간격 늘리기, 텍스트 바 생성 후 길이를 검은 영상과 맞추기
  4. 엔딩검색어로 '검은배경', 플레이 헤드 마지막에 위치, 길이 4초 정도 조절, 텍스트 삽입(길이조절까지)
  5. 애니메이션 효과효과 선택 후 지속시간 늘리기 — 여기까지 기본 시각적 편집 완료, 다음부터 오디오 영역 시작

오디오 편집 — 청각효과 1·2·3

  1. 청각효과 1 · 텍스트를 음성으로텍스트 클립 선택 후 음성 생성
  2. 배경음악 생성음악 장르 선택 → 볼륨 조절(줄이기) → 영상 마지막에 맞춰 분할 → 뒷부분 선택 후 삭제
  3. 청각효과 2 · 배경음악 완성길이 맞춰짐, 음악이 갑자기 뚝 끊기면 페이드 아웃 적용(서서히 꺼지기)
  4. 청각효과 3 · 효과음타자기 효과 — 글씨에 맞춰 타자기 소리(무료버전) 적용, 글씨 들어가는 타이밍에 맞춰 클립 위치 조절, 뒷부분은 분할 삭제
